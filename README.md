## Python Day 1 Projects

Welcome to my first Python project collection! This repository contains three beginner-friendly programs created as part of my software development learning journey.

## Projects

### 1. Calculator (`calculator.py`)
A basic calculator that supports:
- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling

### 2. Temperature Converter (`temperature_converter.py`)
Converts temperatures between:
- Celsius and Fahrenheit
- Fahrenheit and Celsius

### 3. Expense Calculator (`expense_calculator.py`)
Records daily expenses and calculates:
- Total expenses
- Average expense
- A summary of individual expenses

## Requirements

- Python 3
- A terminal or command prompt

## How to Run

Download or clone this repository, open a terminal in the project folder, and run any program:

```bash
python calculator.py
python temperature_converter.py
python expense_calculator.py
```

On some systems, you may need to use `python3` instead of `python`.
